# Happy Tails — Pet Companion

C# Windows Forms application developed for CIS 305: Application Programming II at Flagler College.

## Project overview

Happy Tails is a virtual-pet application that allows users to select and customize a dog, cat, pig, or hedgehog and interact with the pet through feeding, playing, and cuddling. The application includes mood check-ins and a mood-history interface.

## Implementation

- C# and Windows Forms on .NET Framework 4.8.1
- Shared `Pet` class with `Dog`, `Cat`, `Pig`, and `Hedgehog` subclasses
- Event-driven forms, pet-specific interactions, and input validation
- SQL Server and ADO.NET for storing and viewing mood-history data
- Form designer resources and pet artwork
