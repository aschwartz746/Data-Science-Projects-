### 1. Social Media, Sleep, and Mental Health — Machine Learning

**Course:** CIS 315 — Machine Learning  
**Tools:** Python, pandas, scikit-learn, Jupyter Notebook

For this group project, we analyzed a dataset containing 8,000 observations to examine relationships between social media usage, sleep, and mental health.

I developed the Random Forest model and completed much of the Python programming, including data analysis, visualizations, and model evaluation. My teammates worked on KNN and Logistic Regression models.

We compared the models using their predictive performance, and I used GridSearchCV to tune the Random Forest model. I also examined feature importance to better understand which variables influenced its predictions.

The Random Forest model achieved approximately **86% test accuracy** and was our recommended model.

We focused on three personality measurements: Neuroticism, Extraversion, and Openness to Experience. We compared these variables with reported alcohol, cannabis, and nicotine consumption.

The project helped me gain experience working with both numerical and categorical variables, using R for statistical analysis, and interpreting results from a real dataset.

**Project files:** R analysis script and original HTML report.
