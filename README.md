### 1. Social Media, Sleep & Mental Health

**Python · Supervised Machine Learning · Classification · Group Project**

This project explored how social media behavior, sleep patterns, and related factors may be associated with mental health outcomes. Using a dataset of approximately 8,000 observations, our team examined the variables, prepared data for modeling, and compared several supervised machine learning approaches to understand their predictive performance.

The project included **k-nearest neighbors, logistic regression, random forest, and gradient boosting**. My primary contribution was developing and evaluating the **random forest classifier**, including examining its performance and comparing its results with the other models developed by the team. The work provided practical experience in classification, model comparison, and interpreting results in the context of a real-world topic.

**Key focus:** Data preparation, classification models, performance evaluation, and collaborative analysis.

### 3. Personality Traits & Substance Use

**R · Statistical Analysis · Data Visualization · Collaborative Project**

This statistical analysis examined relationships between personality characteristics and reported substance use using the **UCI Drug Consumption dataset**, which includes 1,885 respondents. The project involved working with the data in R, producing descriptive summaries, exploring group differences, and presenting results through statistical output and visualizations.

The report includes analyses of personality scores and substance-use categories, along with graphical comparisons and inferential statistical methods. The project strengthened my experience using **R for data transformation, statistical testing, visualization, and communicating quantitative findings** in a complete analytical report.

### 4. Customer Segmentation with K-Means

**Python · Unsupervised Machine Learning · Clustering**

This project focused on **customer segmentation**, a common business application of unsupervised machine learning. Rather than predicting a predefined outcome, the analysis used **k-means clustering** to identify groups of customers based on similarities in the available data.

The project provided an opportunity to explore how clustering algorithms organize observations and how the resulting groups can be interpreted as potentially meaningful customer segments. It also demonstrated the difference between supervised predictive models and unsupervised methods used to discover patterns when class labels are not provided.

**Key focus:** Unsupervised learning, k-means clustering, customer grouping, and interpretation of clusters.

[**View Python notebook**](Customer_Segmentation_KMeans.ipynb)
