
# Data Science & Machine Learning Projects

A collection of individual and collaborative projects from my undergraduate Data Science coursework at Flagler College.

My work focuses on exploring datasets, identifying patterns, building predictive models, and evaluating machine learning techniques using Python. These projects demonstrate my experience with classification, regression, clustering, data preprocessing, and model evaluation.

## Featured Projects

### 1. Social Media, Sleep, and Mental Health — Machine Learning

**Course:** CIS 315 — Machine Learning  
**Focus:** Classification, Random Forest, hyperparameter tuning

For my CIS 315 final project, my group analyzed a dataset containing 8,000 observations to explore relationships between social media usage, sleep, and mental health.

I was responsible for most of the project's implementation, including data analysis, visualizations, and developing the Random Forest classifier. My teammates developed the K-nearest neighbors and logistic regression models.

Using Python and scikit-learn, I built a machine learning pipeline, used GridSearchCV to tune hyperparameters, compared training and validation performance, and created feature importance visualizations.

**Result:** Our Random Forest model achieved approximately **86% test accuracy**, outperforming the other models and becoming our recommended approach.

[View Machine Learning Project](CIS_315_Final_Project.ipynb)

### 3. Customer Segmentation — K-Means Clustering

**Focus:** Unsupervised learning, customer segmentation, clustering

This project explores how K-Means clustering can be used to identify groups of customers with similar characteristics.

I worked with customer data, applied preprocessing techniques, and used the elbow method to examine the appropriate number of clusters.

The project demonstrates how unsupervised learning can reveal patterns in data without predefined target labels.

**Key Skills:** K-Means clustering, data preprocessing, customer segmentation, exploratory analysis

[View Customer Segmentation Project](Customer_Segmentation_KMeans.ipynb)

### 4. Regression Pipelines and Model Tuning

**Focus:** Regularization, preprocessing, machine learning pipelines

In this assignment, I explored regression techniques and machine learning workflows using Python and scikit-learn.

I worked with Ridge and Lasso regression, StandardScaler, polynomial features, and scikit-learn Pipelines. I also used GridSearchCV to explore hyperparameter combinations and compare model performance.

This project helped strengthen my understanding of how preprocessing, model selection, and hyperparameter tuning fit together in a machine learning workflow.

**Key Skills:** Ridge regression, Lasso regression, pipelines, feature scaling, GridSearchCV
