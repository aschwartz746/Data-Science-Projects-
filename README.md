# Personality Traits and Substance Use — R Statistical Analysis

**Course:** CIS 351 — Introduction to Data Analytics, Flagler College  
**Language:** R  
**Project type:** Collaborative coursework

## Overview

This project examines a drug-consumption dataset with **1,885 respondents**, exploring personality measures such as neuroticism, extraversion, and openness to experience alongside alcohol, nicotine, and cannabis consumption categories.

The original report includes descriptive statistics, grouped summaries, visualizations, and statistical tests. The analysis uses R packages including `tidyverse`, `dplyr`, `ggplot2`, `ggpubr`, `janitor`, and `ucimlrepo`.

## Files

- [`analysis.R`](analysis.R) — R source code extracted **in order** from the original HTML report, with code chunks separated by comments.
- [`original_report.html`](original_report.html) — original exported report, including the written analysis, outputs, and plots. Download and open locally to view the complete report.

## Data source

The original report retrieves the **UCI Drug Consumption (Quantified)** dataset using `fetch_ucirepo(id=373)`.

## Running the code

Install R and the packages referenced at the top of `analysis.R`, then run the script in an R environment with internet access for the dataset download. **The extracted script has not been executed or tested here.** The original code may require adjustments for package versions or data retrieval changes.
