# EC_SQL — Microsoft Access Database Project

**Microsoft Access · Relational Databases · SQL**

## Project overview

EC_SQL is a database project saved in Microsoft Access (`.accdb` format). This project highlights database-focused coursework alongside the Python, R, and C# projects in the main portfolio.

## Project file

**Database:** `EC_SQL (2).accdb`

The database file still needs to be added to this folder before visitors can download and inspect it. Unlike a Python notebook, a Microsoft Access database cannot be interactively explored in GitHub's file preview.

## How to view the database

1. Download the `.accdb` file once it is available in this folder.
2. Open it using Microsoft Access on a compatible Windows computer.
3. Review the database objects, tables, relationships, queries, and any forms or reports that are present.
